# Captures de l'app

Captures réelles de l'app (iPhone 16 Plus, 1290×2796, app en français), utilisées par la page d'accueil et par `portfolio-hover/`.

| Fichier | Écran | Utilisé par |
| --- | --- | --- |
| `calendar.png` | Calendrier partagé, événements des deux | Deux agendas, Un seul espace (fusion), Ce que vous partagez |
| `merge-me.png` | Calendrier avec les seuls événements d'Alex | Un seul espace (téléphone « Moi ») |
| `merge-partner.png` | Calendrier de Camille, ses seuls événements | Un seul espace (téléphone « Toi ») |
| `cycle.png` | Règles, vue du jour | Ce que vous partagez › Cycle |
| `position.png` | Carte avec les deux positions | Ce que vous partagez › Position |
| `nous.png` | Onglet Nous (jours ensemble, rendez-vous, listes) | Ce que vous partagez › Vos jours |
| `ping.png` | Petit mot reçu | Ce que vous partagez › Petits mots |
| `lists.png` | Liste de courses partagée | Ce que vous partagez › Listes |

Le couple (Alex et Camille), les lieux et les événements sont inventés. Les captures sont faites sur la copie locale du backend (pile Docker de répétition), jamais sur `api.nous-deux.app`, avec la barre d'état fixée à 9:41 (`xcrun simctl status_bar … override`).
